# 模型预览示例

本目录按“一模型一文件夹”组织：模型文件、材质文件及贴图均放在同一个模型目录内，移动时请整体保留该目录。项目自建的最小 OBJ 示例可通过主面板的 **Load local model...** 打开，无需额外下载模型。

- `cube/cube.obj`：配套 `cube.mtl`，六个四边形组成的立方体，用于观察自动三角化、法线生成和相机移动；不依赖贴图。
- `textured-quad/quad.obj`：配套 `quad.mtl` 和 `贴图.ppm`，单个四边形模型，用于观察外部贴图加载与 UV 方向。

这些模型与材质均由本项目自行编写，供学习和验证使用，不包含第三方模型素材。这里只保留资源，不提供独立测试程序。
